How to get a Breach Directory API Key

To search for compromised credentials, you can get a free API key from RapidAPI.

  1. Visit the Breach Directory page on RapidAPI.
  2. Sign up for a free account.
  3. Subscribe to the "Basic" plan (it's free).
  4. You will find your API key on the API endpoints page.
